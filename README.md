# Jedahari

Build a high-end, minimalist web app prototype called "JedaHari" using Tailwind CSS and shadcn/ui components. Important: All user-facing text, menus, buttons, and content inside the application must be written in beautiful Indonesian language. Key UI Structure & Content (Translate all UI content to Indonesian):

Header Section: Clean typography with the brand name "JedaHari" and a short Indonesian tagline "Temukan ruang di sela rutinitasmu." Include a dark mode toggle.

Top Section: A premium, dynamic 24-hour circular gauge visualizer showing the balance between mandatory hours (Jam Kerja/Sekolah & Jam Tidur) and the resulting free time ("Waktu Bebas").

Middle Section: Directly below the visualizer, place 3 clean, card-style mood selector buttons in Indonesian: "🔋 Masih Bertenaga", "🪫 Butuh Rehat", and "🤯 Penat Pikiran".

Action Button: A sleek, modern primary button labeled "Rancang Jeda Hari".

Results Section: When clicked, smoothly animate and reveal 3 curated micro-activity cards tailored to the chosen mood in Indonesian (e.g., 5-min box breathing for 'Penat Pikiran', acoustic playlist for 'Butuh Rehat', or micro-hobby for 'Masih Bertenaga'). Each card must feature an elegant, minimal countdown timer widget. Design Requirements: Premium aesthetic, extensive use of whitespace, smooth transitions, and a fully mobile-responsive layout.
